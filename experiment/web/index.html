✦ 结论

Q2Q 达到最高语义对齐度（平均相似度 = 0.751），显著优于直接内容嵌入 Q2C（差距 = +0.110，Cohen's d = 1.44）。该优势在全部 5 个问题类别中均一致成立（所有 p < 1e-25）。方法排序为：Q2Q ≈ Q2P > Q2N >> Q2C > Q2R。这证实了将假想查询作为记忆索引所生成的嵌入，更贴近用户实际的检索表述。

✦ 结论

Q2Q 在改写条件下表现出最高的下降率（平均约 10.8%），表明其对查询措辞高度敏感。然而这恰恰是优势所在：Q2Q 的基线对齐度极高（0.751），即使经历最大幅度下降（场景类：-12.1%），仍然超过 Q2C 的原始得分。方差比（Q2C/Q2Q = 0.86）证实 Q2Q 捕获了更丰富的语义信号——包括措辞细微差异——而非噪声估计。高敏感度 + 高上限 = 精确性，而非脆弱性。

总结

🎯

对齐性

Q2Q 生成的嵌入比直接内容嵌入（Q2C）更贴近真实查询 15.5%，胜率 93.2%，Cohen's d = 1.44。

🛡️

精确性

Q2Q 对措辞的更高敏感度反映的是精确性而非脆弱性。即使最坏情况的下降仍使 Q2Q 高于 Q2C 的基线表现。

📈

可扩展性

10 倍池扩展仅 −8.5% MRR 衰减。Q2Q 在所有规模下均占优，最大池时保持 +0.167 的领先优势。
